# Metadata Schema

| Field | Description |
|---|---|
| Project | Project or framework name |
| Task | Primary specialized task |
| Offline | Can operate without Internet |
| Edge Ready | Suitable for edge deployment |
| Tested Platforms | Known compatible hardware/platforms |
| License | Primary software/model license |
| Commercial Use | Commercial usage allowed/restricted |
| Proven Use Cases | Known real-world applications |
| Source | Official repository or project page |
| Additional Context | Deployment notes or engineering context |
